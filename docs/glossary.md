# Glossary

**AI governance** — Policies, roles, evidence, and controls used to oversee AI systems throughout their lifecycle.

**Anomaly** — An observation or behavior that differs materially from an expected pattern.

**Concept drift** — A change in the relationship between model inputs and the target outcome.

**Data drift** — A change in the statistical distribution of input data compared with a reference period.

**Data lineage** — Traceable history of where data came from and how it was transformed.

**DAX** — Data Analysis Expressions, the formula language used by Power BI and related Microsoft semantic-model products.

**Evidence artifact** — A report, metric set, model card, test result, approval, or other record supporting a validation conclusion.

**Explainability** — Techniques and documentation intended to help humans understand factors associated with model behavior.

**Feature** — An input variable used by a machine-learning model.

**Ground truth** — The observed outcome used to evaluate a prediction.

**Model card** — Structured documentation describing a model's purpose, data, evaluation, limitations, and responsible-use considerations.

**Model inventory** — A controlled record of models, versions, owners, purposes, status, and related evidence.

**Model monitoring** — Ongoing observation of model inputs, outputs, performance, drift, incidents, and operational health.

**Precision** — Among predicted positive cases, the proportion that are actually positive.

**Recall** — Among actual positive cases, the proportion correctly identified.

**Reproducibility** — Ability to repeat a run with recorded data, code, configuration, dependencies, and random state.

**SageMaker** — AWS services for building, training, deploying, registering, and monitoring machine-learning models.

**Validation plan** — A versioned statement of scope, methods, data, metrics, thresholds, responsibilities, and acceptance criteria.

**Verification** — Confirmation that an implementation conforms to specified requirements.
