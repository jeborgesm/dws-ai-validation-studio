# Definition of Done

A feature is done when all applicable conditions are met:

- Behavior is implemented through the intended architectural layer.
- Automated tests cover success, failure, and relevant boundary cases.
- Static analysis and test suites pass.
- API contracts are typed and documented.
- Security, privacy, and data-boundary implications are reviewed.
- User-facing and technical documentation are updated.
- Important design choices are recorded in an ADR.
- Limitations and deferred work are explicit.
- Sample data and outputs are safe for a public repository.
- The change can be explained and defended without relying on undocumented assumptions.
