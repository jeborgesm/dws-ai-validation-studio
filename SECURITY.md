# Security Policy

## Supported status

The project is currently a local educational implementation and is not approved for regulated or confidential production data.

## Reporting a vulnerability

Do not disclose sensitive vulnerability details in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile.

## Data warning

Never submit proprietary, customer, health, financial, or personally identifying data to this project.

## Current limitations

Authentication, authorization, upload-size limits, malware scanning, persistent audit controls, secret management, and hardened cloud deployment are planned rather than complete.
